# Deny Nurcahyanto — Portfolio

Portfolio website built with React, Vite, GSAP, and React Bits–inspired UI motion.

## Structure

- `src/App.jsx` — main page layout and motion setup
- `src/components/` — reusable section and card components
- `src/data/portfolio.js` — content data for skills and projects
- `src/main.jsx` — app entry point
- `style.css` — original design system and component styling

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
