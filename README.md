# Deny Nurcahyanto — Portfolio

Personal portfolio website of **Deny Nurcahyanto**, Junior Developer based in Indonesia (WIB).

A single-page static site (HTML/CSS/JS with GSAP animations and React Bits–style components) featuring:

- Animated hero with custom cursor (desktop) and social links
- About, skills, and three real projects: Kantor AI 9Router, YouTube Shorts Automation, and Village Campaign Media (Plesungan)
- Dark theme with electric blue/cyan accents

## Live

- Deployed on Vercel (this repository is the source; every push to `main` redeploys automatically once the project is linked).

## Structure

- `index.html` — the whole site in one self-contained file (fonts and GSAP load from CDN)
